Each spoken sentence gets its own relevant visual: if the VO says "a cookery student", show an animated cookery
student; "two jobs" → two workplaces; "placement" → a placement setting. Text notes laid over an unrelated graphic
are not enough.

**Why:** the user said so on Decoder #3 (2026-10-26) after the s7–s11 rules were shown as note bars over the timesheet.

**How to apply:** when storyboarding, map every script line to a scene before building; use the costume rigs in
`videos/shared/outfits.py` (`alex_as(prefix, outfit)`) and travel between scene cards with camera moves.
